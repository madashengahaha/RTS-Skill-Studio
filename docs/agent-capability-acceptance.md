# Agent 能力边界与技能验收

## 完成标准

Agent 的职责是正确配置框架已经支持、且 Studio 已有可执行契约的需求，
并准确识别其他需求的缺口。不能用“所有策划技能都必须配出来”衡量完成度，
也不能用现有技能案例数量代替能力覆盖度。

每项需求分别记录：

| 维度 | 证据与判断 |
| --- | --- |
| 战斗框架 | 实际字段读取、动作处理、事件时序、运行时约束和测试；字段存在不等于机制实现 |
| Studio 契约与编译器 | 动作参数、实体字段、引用、默认机制、支持操作及编译校验；框架支持不等于 Studio 可以输出 |
| 案例与验证 | 既有配置、无案例组合测试、Excel 回读、战斗运行验证；各自独立记录，不能互相替代 |

各维度使用：支持、部分支持、不支持、证据不足。缺少案例不能证明不支持；
缺少契约或源码访问不能证明运行时不支持。结论必须附证据位置和未检查范围。

## 配置与缺口处理

1. 拆解目标选择、条件、事件、时序、行为、状态生命周期、数值来源及引用。
2. 查完整能力目录，再按动作、实体、枚举和嵌套类型读取具体契约；注意分页与截断。
3. 有案例时可参考；没有案例时依据实现语义与契约组合，禁止照抄无关技能。
4. 用户参数不足或描述歧义：NeedsClarification，不补造伤害、持续时间、概率等值。
5. 证据不足：明确需要补查的实现或契约，不将内部技术问题推给用户猜测。
6. 有证据的能力缺口：Unsupported，标明 Runtime、StudioContract 或 StudioCompiler
   层、证据、受阻要求及补全位置。部分支持不得静默降级或生成完整 Ready。
   单个动作缺少参数不证明整个框架或契约不能组合表达；完整路径未排查时仍为证据不足。
7. Ready 必须覆盖完整请求，经过确定性编译和校验；审阅确认后才写入。

当前只读工具提供契约和配置证据，不提供任意源码浏览。Agent 不得声称已经
检查工具未返回的源码。开发阶段由 Codex 检查仓库实现并补充通用契约，不能
为某个技能名称或 ID 写生产分支。运行时尚未提供的证据应继续标为证据不足。

## 通用需求语义审查

用户复核后明确：原始刀扇描述包含旋转身体、向四周发射多枚刀刃载体、命中
造成范围伤害；之前测试输入由 Codex 缩减为直接范围伤害并限制为英雄。
因此此前只能证明缩减测试的写入回读成功，原始刀扇的语义验收失败。
不能把这种自行删减后的测试作为 Agent 理解原文正确的证据。

新增通用检查流程适用于所有创建和修改请求，不依据具体技能名或资产 ID 分支：

1. 生成前拆分原始需求中的行为、发射方式、载体、目标、选择规则、时序、数值、
   生命周期和表现；查询完整参数与版本化机制选择契约。
2. 合法 NeedsClarification 保持澄清，不再仅因状态为澄清就启动自动修复。
3. schema 与编译检查通过的 Ready 候选，额外进行一次独立模型调用，审查原始
   请求、历史用户上下文、候选 Plan 和真实工具证据。候选自己的摘要或假设不能
   代替原始需求，也不能用最终结果相似来替代过程要求。
4. 审查结果遵守 `skill-plan-semantic-review.schema.json` v0。每项包含原文摘录、
   维度、需求、Covered/Missing/Uncertain、Plan JSON Pointer、证据 JSON Pointer 和理由。
5. 确定性代码验证报告 schema、原文引用、唯一键与指针是否存在；Covered 必须
   有 Plan 和证据绑定。任意 Missing、Uncertain、非法报告或审查网络失败均阻止 Ready。
6. 修复最多两次；修复后的 Ready 重跑编译与语义审查。耗尽后保留失败结果，
   PlanDisposition 为 ValidationFailed、TurnStatus 为 NeedsClarification，界面不能进入写入。

审查记录放入 ToolExecutions 的内部 `review_plan_semantics` 项，含候选 Plan 哈希和报告；
它不是模型可调用的写工具。对外手工提交 Plan 的编译 API 仍是结构与配置校验，
不应将其编译成功作为 Agent 语义覆盖证明。

此实现增加了独立语义检查和确定性阻断，但语义判断仍来自模型，不能保证
模型必然提取所有要求或理解所有机制；指针存在也不是运行时语义证明。仍需
多机制、不同措辞、无现成案例组合的云端回归和真实战斗验证。

自动测试覆盖未知/空/重复审查报告、伪造原文引用、无效 Plan/证据指针、缺少绑定、
未覆盖需求阻断、修复后重新审查、合法澄清不自动升级。具体行为案例仅用于测试，
